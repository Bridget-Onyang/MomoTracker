# MomoTracker

Understand where your mobile money goes.

Import your MTN MoMo or Airtel Money transactions, see spending by
category, and track savings goals.

## Features (planned)
- Import transactions by pasting messages or uploading a file
- Automatic parsing and categorization
- Monthly dashboard: income vs. expenses, spending by category
- Savings goals

## Tech stack
Flutter · PostgreSQL

## Privacy
We never ask for or store mobile money PINs. Users can delete
all their data at any time.
